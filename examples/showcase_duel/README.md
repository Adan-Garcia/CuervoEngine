# Cuervo Duel (showcase_duel)

The Phase 11 capstone (DESIGN.md section 6): a two-player networked duel with a localized HUD, a custom
post-process shader and an atlas-based sprite scene.

```sh
cuervo --game examples/showcase_duel                                   # one screen
cuervo --game examples/showcase_duel --net-host 7777                   # player 0
cuervo --game examples/showcase_duel --net-join 127.0.0.1:7777         # player 1 (add --net-mode rollback to both)
```

Move with WASD or the arrows, fire with Space, cycle the display language with L (English, Arabic,
Japanese). The first player to press Fire in the menu starts a short countdown; the match is first to 7 hits.

## What it shows

| Feature | Where |
| --- | --- |
| Networking (lockstep or rollback) | nothing in `scripts/duel.plm` reads the network; input arrives as `Input.held_by(player, action)`, as in `examples/netduel` |
| Localization | `locale/strings.csv` (en, ar, ja, with CLDR plural forms); `Locale.load`, `Locale.tr_args`, `Locale.tr_plural`, `Locale.format_int`; the HUD mirrors under `Locale.is_rtl()` |
| Shaped text | fallback fonts in `[text] fallbacks` (Arabic joining and bidi, Japanese kana and kanji) |
| Atlas sprites | `assets/duel.atlas` packs `assets/art/*.png` (and two sprite sheets) into one page; ships are `AnimatedSprite2D`, the backdrop a `Sprite2D`, panels and buttons 9-slice (`Canvas.nine_patch`) |
| Custom shader | `shaders/grade.glsl` (chromatic fringe, split grade, scanlines; `@export` uniforms set in `[render.post.params]`), run after the built-in bloom and vignette |
| Profile | below |

The language is per player: each player's `lang` presses are simulation state (so replays and rollback agree), and
each machine applies only its own player's choice. The locale itself is display state outside the state hash.

## Regenerating the assets

```sh
python3 examples/showcase_duel/tools/make_art.py                       # PNGs and duel.atlas (Pillow)
cuervo-tools shader build examples/showcase_duel                       # shaders/grade.cshader
# fonts: subset with fontTools, then import with shaping and the translation table's codepoints
python3 examples/showcase_duel/tools/make_fonts.py NotoSansArabic-Regular.ttf MPLUS1p-Regular.ttf
cmake --build build/<name> --target showcase_make_efont
build/<name>/tests/showcase_make_efont assets/fonts/NotoSansArabic-subset.ttf assets/fonts/NotoSansArabic-subset.efont locale/strings.csv
```

(`cuervo --font ... --export` imports only Latin without shaping data, so fallback fonts for Arabic and Japanese
need `showcase_make_efont`.) All art is generated by `make_art.py`; the fonts are Noto Sans Arabic and M+ 1p,
subset, under the SIL Open Font License (`assets/fonts/LICENSES.txt`).

## Profile

`cuervo --game examples/showcase_duel --backend gl --profile --trace duel.json --screenshot out.ppm --screenshot-tick 1200 --press ...`
(GL, offscreen video driver, RTX 3060 Ti; a scripted 1200-tick match). The full table is in
`docs/perf/showcase_duel-profile.txt`; the per-system tick cost (average, 300-frame window):

| Zone | avg ms | max ms |
| --- | --- | --- |
| simulation (tick) | 0.134 | 0.178 |
| ... scripts / update | 0.051 | 0.077 |
| ... scene flush | 0.021 | 0.032 |
| ... particles + colliders | 0.007 | 0.015 |
| ... gc | 0.007 | 0.015 |
| render (draw + flush) | 0.772 | 2.958 |
| frame | 0.942 | 3.125 |

The simulation uses under 1% of the 16.7 ms tick budget. Most script time is in drawing: `Canvas.text` is 37% of
script self-time (about 11 text calls a frame for the localized HUD), then `Canvas.sprite`. The Pluma heap stays at
228 live objects with nothing collected over the run. `--trace` writes a Chrome trace for ui.perfetto.dev.

## Tests

`showcase_duel_netplay_lockstep`, `_rollback` and the `_relay_` variants (two headless processes over UDP loopback or
`tools/net/relay.py`, same state and snapshot hash, replays verified by the editor), and `showcase_duel_languages`
(one run per language: no warnings, same hash and frame on 1 and 8 job threads, three different frames, replay
verifies).
