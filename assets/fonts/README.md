# Bundled fonts

- `LiberationSans-Regular.ttf`: Liberation Sans 2.1.5 (Arch `ttf-liberation`
  2.1.5-2), SIL Open Font License 1.1, see `LiberationSans-LICENSE.txt`.
  Chosen because it is permissive, small (410 KB) and has a legacy `kern`
  table, which the importer reads through FreeType. Used by the runtime demos
  and the font import tests.
